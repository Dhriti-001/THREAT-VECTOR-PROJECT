🎓 College Viva Concept: How This Machine Learning Feature Works

1. TF-IDF Vectorization Converts raw textual messages into numerical feature vectors by weighting term frequency ($TF$) inversely against document frequency ($IDF$). High-signal indicators like 'urgent', 'otp', 'expire', and '.top' receive elevated weights.
2. Logistic Regression Classifier Applies the logistic sigmoid function $\sigma(z) = \frac{1}{1 + e^{-z}}$ to map arbitrary linear combinations of features to a calibrated probability between 0% (Benign) and 100% (Malicious).
3. Heuristic Cyber Defense Rules Complements the statistical ML model with deterministic rules inspecting top-level domains (.xyz, .top, .ru, .club), suspicious IP addresses, and credential harvesting patterns.
